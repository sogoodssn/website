# Asaph Generation Website

This is a responsive static website for AsaphGeneration.org.

## Files
- `index.html` — complete website
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation
- `assets/` — images

## Recommended language strategy
English is the primary language because the organization works with U.S. senior centers,
schools, students, and community partners. Korean is included beneath key sections for
Korean-speaking seniors, parents, and supporters.

## Before publishing
1. Replace or add real performance photos after receiving photo/video permission.
2. Confirm Paul Ha's official leadership title.
3. Add the correct contact email once Google Workspace or email forwarding is configured.
4. Review volunteer, privacy, photo-release, and safeguarding policies.
5. Update impact numbers only with documented activity.

## Free publishing options
- GitHub Pages
- Cloudflare Pages
- Netlify

The domain `asaphgeneration.org` can be connected after the site is published.
